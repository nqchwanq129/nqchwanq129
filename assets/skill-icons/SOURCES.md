# Icon sources

- Official Skill Icons SVGs: https://github.com/tandpfun/skill-icons (MIT; see LICENSE). Dark variants are used where available.
- SQL Server: https://github.com/devicons/devicon (see LICENSE-devicon), placed on a rounded tile.
- VMware and Veeam: existing embedded logos from assets/tech, placed on rounded tiles.
- IIS: local text tile.

The four fallback tiles are local adaptations, not official Skill Icons assets.
